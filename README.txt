AP ENTERPRISES – COMPLETE WEBSITE & MARKETING PACKAGE

WEBSITE PAGES (11):
Home (index.html), About Us, Products, Solutions, Services, Resources, Customers, Gallery, Contact, Product Enquiry, Repair / Service Request.

HOW TO PREVIEW:
1. Extract this ZIP to a folder.
2. Open index.html in a browser, or run `python -m http.server 8000` from the folder and visit http://localhost:8000.
3. Keep the `assets`, `brochures`, and `resources` folders alongside the HTML pages.

HOW TO PUBLISH:
Upload the entire folder contents to a static host such as GitHub Pages or Netlify. Set the publish directory to the folder containing index.html. Configure a custom domain only after DNS is ready.

FORMS:
The contact, product enquiry and service request forms open a prefilled email to apentglobal@gmail.com. This static version does not store enquiries or upload attachments. For an admin panel, database, secure file uploads and email notifications, connect a backend such as Supabase.
